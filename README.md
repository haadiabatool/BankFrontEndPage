# CREDIX - Banking Landing Page

CREDIX is a modern banking landing page built using HTML and Tailwind CSS.  
The project focuses on clean UI design, responsive layout, and smooth user interactions.

## Features
- Modern banking homepage UI
- Hero section with banking promotion
- Banking detail section
- Support/Contact form
- Hover animations and transitions
- Tailwind CSS styling

## Technologies Used

- HTML5
- Tailwind CSS
- Vite
- JavaScript
